# IssueFlow

A fullstack issue tracking application built with react, Node.js, Express, SQLite and Playwright. Includes REST API, automated E2E testing and CI/CD.

## Features

- Ticket management
- Search and filtering
- REST API
- Automated E2E Testing
- CI/CD pipeline

## Tech Stack

Frontend:

- React
- TypeScript
- SCSS

Backend:

- Node.js
- Expess
- SQLite

Testing:
Playwright
